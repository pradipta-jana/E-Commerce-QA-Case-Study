# Application Overview

## 1. Application

**Application Name:** Automation Exercise  
**Domain:** eCommerce  
**Type:** Web Application  
**SUT:** https://automationexercise.com/

Automation Exercise is an eCommerce practice application designed for learning and demonstrating web and API automation testing.

## 2. Purpose of the Case Study

This case study demonstrates an end-to-end QA Engineering approach for an eCommerce application.

The project will cover both manual and automation testing, with Jira used for QA management and GitHub used for source control and documentation.

## 3. Initial Business Areas

The initial scope will focus on five major business areas:

1. Customer Account Management
2. Product Discovery
3. Shopping Cart
4. Checkout
5. Order Management

## 4. QA Approach

We will progressively demonstrate:

- Requirement analysis
- Test scenario and test case design
- Functional and regression testing
- Defect management
- UI automation
- Test reporting


## 5. Project Objective

The goal is not to achieve complete application coverage. The goal is to demonstrate how a QA Engineer can take a business workflow from requirement analysis through testing, defect management, automation and reporting.
