# Customer Account Management Requirements

## REQ-CAM-01 — Customer Registration

The application should allow a new customer to create an account by providing the required registration and personal information.

**Jira:** [KAN-7](https://pradipta-qa-portfolio.atlassian.net/browse/KAN-7)

## REQ-CAM-02 — Existing Email Validation

The application should prevent a customer from creating a new account using an email address that is already registered.

**Jira:** [KAN-8](https://pradipta-qa-portfolio.atlassian.net/browse/KAN-8)

## REQ-CAM-03 — Customer Login

The application should allow a registered customer to log in using valid credentials.

**Jira:** [KAN-9](https://pradipta-qa-portfolio.atlassian.net/browse/KAN-9)

## REQ-CAM-04 — Invalid Login Validation

The application should prevent login when invalid credentials are provided and display an appropriate error message.

**Jira:** [KAN-10](https://pradipta-qa-portfolio.atlassian.net/browse/KAN-10)

## REQ-CAM-05 — Customer Logout

The application should allow a logged-in customer to log out and return to the login state.

**Jira:** [KAN-11](https://pradipta-qa-portfolio.atlassian.net/browse/KAN-11)

## REQ-CAM-06 — Customer Account Deletion

The application should allow a logged-in customer to delete their account and display an appropriate confirmation after successful deletion.

**Jira:** [KAN-12](https://pradipta-qa-portfolio.atlassian.net/browse/KAN-12)
