## 2. Test Scenarios

Test scenarios are derived from the selected business workflow and represent the major functional areas to be validated.

### Scenario 01 - Authentication

**TS 01 AUT 01** - Verify that a registered user can log in with valid credentials.

**TS 01 AUT 02** - Verify that an authenticated user can log out successfully.

### Scenario 02 - Product Search

**TS 02 PSR 01** - Verify that a user can search for a product.

**TS 02 PSR 02** - Verify that the appropriate product is displayed for the search.

### Scenario 03 - Product Details

**TS 03 PDT 01** - Verify that the selected product details are displayed correctly.

**TS 03 PDT 02** - Verify that the user can proceed from product details to the cart.

### Scenario 04 - Shopping Cart

**TS 04 CRT 01** - Verify that a product can be added to the cart.

**TS 04 CRT 02** - Verify that the selected product is displayed correctly in the cart.


### Scenario 05 - Checkout

**TS 05 CHK 01** - Verify that the user can proceed from the cart to checkout.

**TS 05 CHK 02** - Verify that the checkout process can be completed with valid information.

**TS 05 CHK 03** - Complete Checkout

### Scenario 06 - Order Placement

**TS 06 ORD 01** - Verify that the user can successfully place an order.

**TS 06 ORD 02** - Verify that successful order placement is reflected in the application.

**TS 06 ORD 03** - Order Completion

### Scenario 07 - Order Verification

**TS 07 OVR 01** - Verify that the order confirmation is displayed after successful order placement.
