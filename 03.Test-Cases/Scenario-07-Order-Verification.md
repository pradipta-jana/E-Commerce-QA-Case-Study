# Scenario 07 - Order Verification

This scenario covers verification of the successfully placed order, including order confirmation, order details, and order history.

---

## TS 07 OVR 01 - Order Confirmation

### TC 07 OVR 01 A - Verify Order Confirmation

**Pre Condition:**

* User is logged in.
* User has successfully completed the order placement process.

**Test Step:**

1. Complete the order placement process.
2. Review the resulting confirmation page.

**Expected Output:**

* The order confirmation is displayed.
* The application indicates that the order has been placed successfully.

**Automation Status:** Automated

---

### TC 07 OVR 01 B - Verify Order Confirmation Message

**Pre Condition:**

* User has successfully placed an order.
* Order confirmation page is displayed.

**Test Step:**

1. Review the confirmation message.
2. Verify the displayed order completion information.

**Expected Output:**

* The confirmation message is displayed correctly.
* The message indicates successful order placement.

**Automation Status:** Automated
