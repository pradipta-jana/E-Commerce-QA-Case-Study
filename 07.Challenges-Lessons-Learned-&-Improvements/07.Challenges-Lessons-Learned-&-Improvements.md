# Challenges, Lessons Learned & Improvements

## Challenges

No significant blockers were identified during the execution of the selected test scenarios.

The implemented and executed happy-path workflows completed successfully across the covered application areas.

From an automation perspective, one of the key considerations was selecting scenarios that provide meaningful regression value while keeping the automation maintainable and reusable.


---

## Lessons Learned

This case study demonstrates several practical QA Engineering principles:

* Understanding the business workflow before designing test scenarios.
* Breaking business functionality into meaningful test scenarios.
* Designing multiple test cases under a single test scenario.
* Maintaining traceability from test scenarios to test cases and execution.
* Separating manual test coverage from automation coverage.
* Prioritizing high-value and repeatable scenarios for automation.
* Not every test case needs to be automated; automation should be driven by business value, repeatability, and maintainability.
* Keeping automation implementation separate from the overall test-case design.
* Reusing common automation components to reduce duplication and improve maintainability.
* Using execution results and observations to guide further testing.
* Maintaining QA documentation alongside testing and automation activities.


---


## Improvements

The current case study focuses on selected business workflows and does not aim to provide complete application coverage.

Potential areas for future improvement include:

* Expanding negative and boundary test coverage.
* Adding additional functional scenarios.
* Increasing automation coverage for suitable test cases.
* Expanding regression coverage.
* Improving test-data management.
* Increasing cross-browser automation coverage.
* Introducing API automation.
* Improving execution reporting and test evidence.
* Integrating automated execution with CI/CD.
* Expanding framework capabilities as automation requirements grow.
